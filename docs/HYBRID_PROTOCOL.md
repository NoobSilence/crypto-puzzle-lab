# Hybrid Protocol - AI/Human Merge (22-23 Aug 2026)

This lab operates as an AI/human hybrid.

## Principles

1. **Independence**: external researchers are benchmarks and sparring partners, never authorities. Everything is verified in-house.
2. **AI-first research**: the AI performs all research end-to-end (analysis, strategy, scripts, intelligence, drafts). The human performs only necessary physical actions (run, push, post, verify, decide).
3. **Compounding**: every run feeds the knowledge base; the knowledge base feeds every run.
4. **End goal**: become the reference in crypto-puzzle research.
5. **English-only on GitHub**: all commits, pull requests, issues, code comments, and documentation pushed to GitHub MUST be in English. This is non-negotiable for international collaboration and discoverability.

## Division of labor

| AI | Human |
|----|-------|
| Research, analysis, cross-checks | Run scripts |
| Strategy + target selection | git add/commit/push |
| Write + test scripts | Post messages (AI drafts) |
| Gather community intelligence | Paste outputs back |
| Draft issues/replies (in English) | Go/no-go decisions |
| Self-detect + correct errors | Provide hardware |

## Operating loop

AI researches -> AI drafts script/message (English) -> human runs/posts -> output back to AI -> AI iterates.

## Language policy

- **Internal communication** (AI <-> human chat): any language (Dutch allowed)
- **GitHub public artifacts**: English ONLY
  - Commit messages
  - Pull request titles/descriptions
  - Issue titles/descriptions
  - Code comments
  - Documentation files (.md, .json, etc.)
  - File names
- **Drafts for third parties** (floflo777, Reddit, etc.): English ONLY
