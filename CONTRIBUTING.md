# Contributing to Crypto Puzzle Lab

This repository operates as a systematic AI-human hybrid research lab.

## How to Contribute

Currently, this is a personal research repository. Collaborators should:

1. Write all communication, issues, and pull requests in English (Hybrid Protocol Rule #15).
2. Follow the fail-fast and evidence-based methods in [docs/RESEARCH_METHODOLOGY.md](docs/RESEARCH_METHODOLOGY.md).
3. Pre-validate scripts and avoid exotic or unverified dependencies.
4. Preserve source URLs, timestamps, and evidence labels when adding findings.
5. Never commit API keys, seed phrases, private keys, or other secrets.

## Reporting Issues

Use the GitHub issue tracker. Label issues clearly, for example `bug`, `enhancement`, or `osint-finding`.
